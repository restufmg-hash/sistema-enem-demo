# Sistema ENEM — demonstração pública

Este repositório contém páginas HTML, scripts, catálogo e recursos estáticos usados pela demonstração pública do Sistema ENEM. Não é a fonte editorial de verdade e não substitui o controle privado de aprovação, revisão e gabarito. A integração de novas questões exige validação editorial e publicação explicitamente autorizada.

## Ordem operacional — 20/11/2026

Por decisão do mantenedor, **não haverá desenvolvimento, processamento de provas/questões, testes ou execução de agentes no GitHub Codespaces**. As alterações autorizadas são preparadas fora do Codespaces e sincronizadas pelo GitHub com revisão de diff e integração segura. A mera existência de código publicado ou HTTP 200 não comprova que uma tentativa do aluno tenha sido gravada e recuperada no servidor.

## Manutenção e publicação

- Preservar URLs e aliases antigos, identidade completa da questão, mídia e revisão; não republicar candidatos não aprovados.
- Nunca incluir gabarito antecipado, credenciais, tokens, dados pessoais ou recibos identificáveis de alunos no catálogo, nos arquivos JavaScript ou nos commits públicos.
- Conferir o conteúdo efetivamente distribuído, links, assets, comportamento de tentativa e readback do servidor em ambiente autorizado antes de declarar uma entrega funcional.
- Integrar apenas alterações verificadas. Não modificar frentes editoriais paralelas nem encerrar PRs de conteúdo por uma atualização documental.

Este README documenta a operação, sem afirmar que testes de navegação, persistência ou deploy foram executados nesta atualização.
